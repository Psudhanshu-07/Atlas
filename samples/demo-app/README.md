# TaskFlow

TaskFlow is a small team-collaboration application: orders, inventory,
carts and reporting in one codebase.

## Layout

- `src/ui` — React views
- `src/api` — HTTP controllers
- `src/services` — business logic
- `src/data` — persistence
- `src/utils` — shared helpers
- `tools` — offline report tooling

## Getting started

    npm install
    npm start
